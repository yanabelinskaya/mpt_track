# План выполнения курсового проекта

## 1 неделя
- Подготовка файла с постановкой задачи.  
- Составление списка сущностей проекта.  
- Создание черновика словаря данных.  
- Формирование структуры репозитория Git, включая файл README с планом работ.

## 2 неделя
- Логическое проектирование базы данных (ER-диаграмма, нормализация).  
- Начало работы над специальной частью пояснительной записки: формулировка требований к проекту и таблица ограничений.  
- Разработка первой версии плана миграции данных.

## 3 неделя
- Физическое проектирование базы данных.  
- Реализация базовой серверной логики: создание DDL-скриптов, определение категорий запросов.  
- Загрузка начальных данных.  
- Разработка набора SQL-запросов для CRUD-операций и создания представлений.  
- Обновление пояснительной записки с включением структурной и функциональной схем.

## 4 неделя
- Продолжение разработки серверной логики: написание процедур, триггеров и реализация транзакций.  
- Подготовка SQL-пакета.  
- Создание описания кодов ошибок для словаря API.

## 5 неделя
- Обеспечение безопасности и администрирования: внедрение ролей и прав доступа.  
- Реализация хеширования, маскирования и тонирования данных.  
- Организация резервного копирования (бэкап) и восстановления: подготовка скриптов и инструкций.  
- Формирование отчёта по системам логирования.

## 6 неделя
- Разработка клиентского приложения и API, обеспечение интеграции.  
- Реализация адаптивного веб- или десктоп-приложения (вид не принципиален).  
- Организация импорта и экспорта данных.  
- Завершение спецификации API и подготовка технической документации: схемы интерфейсов, схемы микросервисов (при наличии), руководство по запуску.

## 7 неделя
- Разработка подсистемы аналитики и тестирования: статистика, отчёты, фильтрация и сортировка данных.  
- Импорт данных, создание визуализаций.  
- Подготовка тест-плана и тест-кейсов, ведение журнала прогонов.  
- Составление отчёта по обнаруженным дефектам и их исправлениям.

## 8 неделя
- Комплексная подготовка полной документации по проекту.  
- Подготовка презентации для защиты курсовой работы.
